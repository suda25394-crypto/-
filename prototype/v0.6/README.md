# V0.6｜环形 AI 中枢 + 12 个模块 + 独立小宇宙

2026-11-16 · **手机端原型** · 尚未获得用户验收。

## 依据
用户在 V0.5 五种设计中，只认可 **03 环形 AI 中枢**，并指出此前只做了首页：约会、心愿、回忆、小宇宙等没有独立详情与完整操作。用户明确希望：
- **AI 生成、管理、驱动各模块内容**，用户无需到每个模块重复填表。
- 点击模块查看精简摘要，再展开具体信息。
- 用户可主动手动修改模块中的内容，**AI 对修改进行信息确认**，得到用户同意后才存入记忆。
- 小宇宙也是独立模块，有自己的世界、故事和内容；不能丢失其他功能。

**03 是当前继续深化的样本，不自动等于最终产品全局视觉定稿。**

## 运行
在手机浏览器打开 [index.html](index.html)；是单文件 HTML/CSS/JS 演示，不需要 API Key 或网络服务。不要填写真实隐私数据。

## 已编写的交互
1. 03 号环形 AI 中枢首页，中央单一 AI 入口，四个常用功能节点。
2. 「功能」页共有 **12 个可点击模块**：约会、惊喜、共同记忆、心愿、小宇宙、美食、共同日程、关系沟通、情侣相册、互动游戏、礼物灵感、旅行。
3. **模块详情**：概览标题、简短摘要、详细步骤/故事，均由本地规则与预先撰写的内容组合产生。
4. **手动修改**：改标题/摘要/详情 → AI 修改确认页 → 可选择保存并记住从修改推断出的偏好 → 用户确认后写入本机数据；手动修改过的模块不会被模拟 AI 自动覆盖。
5. **聊天记忆**：输入“不喜欢人多”“喜欢咖啡”“预算100元”等，出现授权确认；只有用户确认才将偏好用于后续相关模块。
6. 「我们」档案页可查看和删除已经确认的偏好。
7. **独立小宇宙页面**：星球视觉、故事章节、场景元素、手动修改和“让 AI 改变世界”的对话入口。

## 边界：AI 的真实程度
页面中静态内容由 GPT 创作，**在手机浏览器上发生的动态调整与“AI 确认”均是 JS 本地规则模拟**。未接入真正 DeepSeek/其他 LLM、服务端关系记忆、情侣双人配对、云端同步或任何外部执行动作。未来真接入模型后，才具备真实 AI 内容生成与语义理解。

## 已测试范围
2026-11-16，Playwright + Chromium 的 390×844、360×740 手机视口：首屏、12 模块、约会详情、编辑与 AI 确认、聊天记忆确认、独立小宇宙、“我们”档案；主流程无 JavaScript pageerror 和横向溢出。浏览器受环境策略限制，file:// 导航与跨刷新本地持久化未做端到端验证；不宣称真实手机和用户验收通过。
