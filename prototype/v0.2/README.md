# 「好好在一起」V0.2｜可交互 AI 情侣生态原型

> **局部交互作品，尚未经用户验收；不是部署上线，也不是完整的 AI 产品。** 本版本的工作名称“好好在一起”仍非正式品牌决定。

## 正确的产品定位
**AI 智能中枢 + 可成长的关系记忆 + 功能导演动态编排 + 丰富、相互独立又能联动的情侣功能生态。**

**小宇宙只是其中一个功能模块，绝不应成为整个 App 的中心。** 这是在 V0.1 出现“宇宙中心化”偏差后的修正原型。

## 运行方式
下载本目录的 [index.html](index.html)，直接使用 Chrome/Edge 等现代浏览器打开，无需安装依赖。采用单文件 HTML/CSS/原生 JavaScript。

## 已编写的可交互演示
- AI 主导的动态首页：输入“周末想约会”“准备惊喜”“今天吃什么”“最近不开心”等请求，本地规则将切换不同的功能编排/建议。
- 展示关系记忆对下一次推荐的影响：更改约会偏好、活动兴趣和预算后，相关建议的文字/说明动态更新。
- 计划收藏、独立心愿添加/删除、回忆胶囊新增/删除、情侣昵称设定。
- 关系守护者示例表达（不会发送给另一方）。
- 「小宇宙」作为独立子页面，有主题切换和最近回忆引用。
- 电脑侧边导航与手机底部导航，使用浅色、柔和卡片界面。

## 真实能力边界
- **不接入 DeepSeek 或任何真实 AI**，使用关键词、模板和预定义规则模拟部分 AI 决策；不能宣称已有智能调度系统。
- `localStorage` 只在当前浏览器本地保存演示资料；没有真实账号、情侣配对、跨设备同步和服务端权限隔离。
- 没有真实天气/餐厅/地图检索、自动执行、推送、会员或付费。
- 不要输入真实敏感资料。

## 验证记录
2026-11-16：用 Playwright + Chromium 在 **1440×1000 桌面**与 **390×844 移动端**检查：页面加载、约会建议、保存计划、修改偏好、新增回忆、切换惊喜建议、切换小宇宙主题。两次执行均未观察到 JavaScript pageerror。此结果**不等于真实设备或完整端到端验收**。
