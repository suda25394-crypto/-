# “双生宇宙 V0.1”｜历史局部原型

> **重要：这是小宇宙 + 心愿等早期功能的演示，不是整个情侣 AI 超级 App 的最终方向或架构。**  
> 2026-11-16 用户明确纠偏：产品真正的核心是**AI 关系记忆、功能导演、秘密策划师、关系守护者等能力驱动的动态功能生态**；小宇宙只是其中一个核心模块。请先读 [当前总纲](../../docs/PROJECT.md) 与 [AI 核心](../../docs/AI_CORE.md)。

## 现有文件
- [index.html](index.html)：原版单页 HTML/CSS/JavaScript，本地可打开的交互演示。
- [产品大纲_V0.1.md](产品大纲_V0.1.md)：当时的产品草稿，**属历史版本，并非当前确认的整体产品规格**。

保留这两个文件的原貌用于回看、复用与版本对比，不直接覆盖或删除。

## 当前能演示的内容
1. 输入两个称呼、共同回忆、可选心愿及偏好标签。
2. 看关键词主题星球与模板故事，进入首页功能卡片。
3. 新增回忆和心愿，查看关键词驱动的三步行动建议。
4. 原型仅使用本机 `localStorage` 保存数据，清理浏览器可能丢失记录。

## 不能代表已经完成的东西
没有真正的 DeepSeek/LLM 调用，没有可管理的长期关系记忆，没有实时的跨模块 AI 导演，没有秘密策划师/守护者的完整逻辑，没有情侣跨设备账号同步，也没有可自由生成的角色和实时 3D 场景。

## 如何体验
下载本目录的 `index.html` 用浏览器打开即可。不要填写真实私密资料。此演示不依赖 API、数据库或订阅费。

**开发下一版时**，应先验证 AI 在多个独立模块之间进行动态编排，而不是只继续扩张星球。
