# 双生宇宙 V0.1｜历史交互原型快照

**状态：已归档的本地演示代码，不是发布版。**

## 立即体验
下载或克隆本目录，在浏览器打开 [index.html](index.html) 即可。推荐先用电脑 Chrome/Edge；手机浏览器若不支持直接打开本地 HTML，可在本机起一个静态服务器再访问。

本原型是单页 HTML/CSS/JavaScript，不需要安装依赖、登录、联网 API 或向任何模型付费。

## 可以体验的流程
1. 点「开启我们的宇宙」；
2. 填写两个称呼、共同回忆、可选心愿，并挑选偏好；
3. 看主题星球与个性化首页；
4. 新增一段回忆，打开模板故事；
5. 添加共同心愿，获取按关键词匹配的三步建议；
6. 回到首页、设置或重置本机数据。

## 尚未实现（不要误认为已有）
- 没有真实 DeepSeek/LLM 请求，AI 交互为本地模板；
- 没有真正生成新的 3D 世界、人物或 AI 原创故事；
- 没有双方的独立账号、跨设备同步或共享权限；
- 没有天气/价格/地图的实时查询、支付或会员系统；
- 没有正式部署或用户真实留存数据。

**注意**：该原型将输入的称呼、回忆和心愿存在浏览器 `localStorage`。避免填写私人敏感信息；清除浏览器数据可能丢失记录。
