# 产品总纲｜双生宇宙（暂名）

更新：2026-11-16｜状态：**已确立方向，产品名与最终形态未定**

## 1. 核心定位
目标是一个**AI 先行的情侣超级 App**（软件、小程序或网站形式尚未确定），服务情侣生活中的多种场景，但不是把常见功能堆成廉价工具箱。

**产品主张**：AI 先认识两个人（在自愿与授权的前提下），为他们创造专属的小宇宙、角色、故事与虚拟空间；通过 AI 协调功能，把共同愿望、回忆、计划与现实生活相连。

两种首先关注的“超能力”：
- **创造世界**：情侣提供少量线索 → 诞生独特星球/空间/角色/故事；共同经历持续改变它。
- **把想法变成行动**：提出心愿/需求 → 通过 AI 调度已有功能，形成可用计划或可执行步骤；完成后反哺数字世界。

二者是优先探索方向，不意味着产品最终只剩两种功能。

## 2. 为什么做
发起者曾制作“AI 调解情侣吵架”的早期尝试，实际反馈是：Bug 较多、只有争吵时才会想到打开，而且情绪激烈时往往不愿打开。这是产品问题经验，而非关于所有情侣的普遍结论。

因此新的产品不应只为冲突而存在；要能在普通一天也让人想进入，既有趣味与惊喜，也有实用价值。

## 3. 核心用户假设（待验证）
- 愿意一起创造、记录与计划生活的情侣，尤其是愿意尝鲜的年轻情侣。
- 重视首次体验的“意想不到”和之后持续成长的意义。
- 可能对同一双人空间中集成的便捷服务与个性化内容感兴趣。
- 是否能够持续使用、付费，仍是**待验证假设**，不能拿创作者个人喜好当市场事实。

## 4. 产品设计立场
- **先是体验，后是功能**：第一分钟应该出现具体惊喜，而不是长问卷或一屏图标。
- **AI 是组织者，不只是聊天框**：可以理解请求，选择模块、产出结构化结果、驱动既有场景。
- **共同创造胜过日常打卡**：让两个人的真实经历影响数字世界。
- **首发不限制总想象力，但要限制开发规模**：先一版能玩，再补其他能力。
- **国内产品不预设弱于海外**：对标国际成熟产品，同时核实本土用户需求。
- **有边界的亲密数据**：双方各自私密、双方共享、单次授权的权限必须明确。

## 5. 一条体验循环
初次对话/轻引导 → 产生独特小宇宙/故事 → 首页展示个性化入口 → 记录回忆或心愿 → AI 生成新场景/可执行活动 → 现实中体验 → 用户选择保存成果 → 世界更新。

## 6. 暂不下结论的事项
