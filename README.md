# 双生宇宙｜AI 情侣超级 App（暂定名）

> 项目状态：创意方向已确立，V0.1 本地交互原型已有文件；尚未上线、未接入真实 AI、未完成双人同步。  
> 最后整理：2026-11-16。仓库用于跨 GPT、Codex、DSH 的**项目事实源**。

## 一句话定位

**一个 AI 先了解情侣，再把共同经历变成专属小宇宙、角色与故事，并把两个人的愿望变成现实行动的双人生活空间。**

不是情侣工具箱里塞进 AI 聊天框；AI 是贯穿体验的协调中枢。

## 当下的两个核心超能力

1. **创造世界**：情侣信息 → 独有的小宇宙、角色、故事/虚拟空间，随着共同经历继续演变。
2. **把想法变成行动**：心愿 → 可执行的现实计划，完成后又反哺世界。

其他超能力暂留创意池；不是不做，而是不在第一版同时开发。

## 第一阶段目标

**先有一份可体验产品草稿和可运行的 V0.1，再根据实际体验修正，不再无休止追问单一功能。**

已有 V0.1 单页 HTML 原型及产品大纲在历史会话交付过，2026-11-16 已将原始文本文件归档到 [prototype/v0.1/](prototype/v0.1/)。**代码已入库，但未正式部署、未接入真实 AI，也尚未获得用户使用体验验收。**
