# 情侣 AI 专属前端 V1

手机浏览器可操作的本地演示，沿用 V0.6 的 03 环形 AI 中枢。使用原生 HTML、CSS、JavaScript 模块，无运行时第三方依赖。

## 启动

在仓库根目录的 Windows PowerShell 中运行，打开 [http://127.0.0.1:4173/](http://127.0.0.1:4173/)。

~~~powershell
py -3.12 -m http.server 4173 --bind 127.0.0.1 --directory frontend
~~~

在 macOS / Linux 上，用 `python3` 替代 `py -3.12`。服务器是本机调试入口，运行时保持终端打开。打开文件地址会受浏览器 ES 模块策略限制，请通过以上 HTTP 地址访问。

## 试用一条完整路径

1. 点中央 **AI**，发送「周末想和女朋友出去玩，预算 200 元」。演示导演会整理约会、共同日程、旅行、心愿四张草稿，首页环绕节点也会变化。
2. 点开约会，展开详情查看预算，再点 **编辑内容 → 查看 AI 确认**。选择保存范围，可自选是否保留一条演示记忆，然后确认保存。继续编辑或关闭确认可返回而不保存。
3. 在右上角切换「演示 A／B」。在 **共同空间** 发带 `@AI` 的消息可触发演示回复，切换账号可以看到共同空间的同一条消息和草稿。
4. 打开 **我们**，查看对方的档案并编辑自己的档案。个人 AI 中输入「我不喜欢人多」，选择「加入我的档案」才会在另一位演示用户可见的档案里出现。之后用同一条约会需求，可以看到模拟建议考虑错峰和安静场所。
5. 打开 **功能** 可进入全部十二项，小宇宙有独立路由和星球故事页。

## 数据与体验边界

演示身份、示例档案、规则分析、草稿及记忆保存在同一浏览器的本地存储。浏览器刷新可保留已保存数据。A/B 切换用于测试用户界面和数据流，安全授权和跨设备同步留待接入。个人对话可见性和公开档案的正式规则以已确认产品决策及后续接入为准。人格图预留结构与文字画像，本版没有载入 Mini-IPIP 题库或生成测量分数。

演示未连接公网 Open WebUI、DeepSeek、云端数据库或 PWA 安装入口，使用示例内容即可。要重新体验空白状态，打开浏览器的隐私窗口，结束后即可关闭该独立会话。

## 验收

现有自动化在 Chromium/Chrome 的 360×800 与 390×844 视口启用触控。测试运行前保持 HTTP 服务器开启。如需在自己的隔离测试环境复跑：

~~~powershell
py -3.12 -m venv frontend/.venv
frontend/.venv/Scripts/python.exe -m pip install playwright==1.65.2
frontend/.venv/Scripts/python.exe frontend/tests/smoke.py --chrome 'C:/Program Files/Google/Chrome/Application/chrome.exe'
~~~

按实际情况替换浏览器路径。追加 `--evidence frontend/evidence` 可重新生成截图。本机的运行结果、服务器接口核对和下一阶段接入办法见 [前端实施记录](../planning/FRONTEND_V1_IMPLEMENTATION_2026-11-17.md)。
