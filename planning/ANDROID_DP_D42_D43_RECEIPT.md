## 两个账号实际做了什么

| 场景 | 操作与实际结果 |
| --- | --- |
| 模块内续聊 | 从同一条约会打开「私下问 DP」和「两人共同续聊」。B 只看到共同讨论。A 请求改动，B 编辑共同草稿并确认，双方读到同一 ID 的新版本。取消保留原文；重复确认只写一次；基于旧版本的请求被拒绝。确认后追问仍包含上一轮对话；撤回记忆后，旧回复从后续模型输入排除。 |
| 双方意愿 | 晚饭与展览分为两条活动。A、B 分别接受晚饭后显示两人已定。B 拒绝展览后仍保留 A 的意愿。重复点击不增加记录，修改活动内容会重新征求意愿。 |
| 情境委托 | 从双方可见的原群消息保存「下次一起挑电影，接着看上次那部」。普通群聊、查看或修改委托均无模型调用。询问今晚看什么时，合成模型收到该委托并在回复中使用。暂缓后停止推荐，恢复后可再次匹配，完成或取消后停止推荐。 |
| 实际体验 | 分别保存收藏、计划、实际参加与事后反馈。「咖啡一般，路上的书摊倒很好逛」关联原活动及 A。仅自己可见时，B 和群聊均读不到；共享后建议可引用 A 的反馈。纠正和撤回后，后续输入同步更新。 |
| 共同回忆小游戏 | 从已确认的共同回忆中选材生成三道选择题。A 答一题后强停重开继续作答，B 只看到自己的待猜选项。B 提交并同意揭晓时答案仍保密。A 也同意后，A、B 各自重登看到 2/3。材料不足、无效模型输出及重复出题已有独立用例。 |

## 跨月记忆与成本证据

合成时间线依次保存 2 月的平日预算 100 元、6 月纠正的 150 元及 8 月的生日例外 200 元，中间插入 120 条无关会话。11 月询问「按平时的花销安排周末」，召回 A 的「把我的平日约会预算改为150元」。追问依据时仍命中同一原话和时间（2026-06-12 18:30 +08:00，来源消息 `recall-topic-0002`）。B 的私聊与共同群查不到 A 的私人预算。A 删除后，150 元与已被替代的 100 元都不会再次进入模型输入。

测试截取了生产网关适配器交给替代传输层的完整请求，首问 2,604 字节，追问 2,718 字节。测试模型固定返回 10 个输入 token，此值仅用来验证计量字段。线上 DeepSeek 调用为 0 次；尚无线上 token、费用或回复质量数据。

SQLite 以授权记录、说话人、话题词及中文双字片段建立索引；模型请求只装载命中证据及近期对话。共同场景仅传已发布记忆文本。本人回溯来源才可读取关联的私聊原话。未知的旧记录时间保留为空。检索质量已用上述合成场景验证，更多口语、跨主题表达与长期使用效果仍需实际使用观察。

## 安装与本机复测

测试包名 `com.coupleai.couple_app`，版本 `0.3.0+3`，最低 Android API 24，含 arm64-v8a、armeabi-v7a、x86_64。APK Signature Scheme v2 验证通过。文件大小 168,184,877 字节，SHA-256 为 `891420d535dca5bc0db71038bdae40a67ce976ce7d517239225c026f7c7f4ce7`。与旧 Demo 使用同一应用 ID，Android 会将其视为更新。

以下命令在本机独立工作树中复测，使用已有 Android SDK、Python 和项目依赖。第一条服务命令须保持运行，默认使用临时合成数据。

```powershell
cd D:\dev\couple-ai-dp
python -m services.couple.tests.fixture --port 18793
```

另开 PowerShell，为测试模拟器接入该服务。

```powershell
D:\tools\android-sdk\platform-tools\adb.exe -s emulator-5554 reverse tcp:18793 tcp:18793
```

打开测试 APK，登录页填 `http://127.0.0.1:18793`。两个合成账号为 `a@example.test`、`b@example.test`，测试口令均为 `fixture-only`。本机关联的回环地址仅供有这条 adb 映射的调试设备使用。公网手机登录要填同版本产品服务的 HTTPS 基址。仅进入「本机演示」会进入旧版离线交互；本轮新增功能使用服务端账号会话。

首次体验可在「约会」新建共同记录，点「两人共同续聊」，输入「把时间改到六点」，编辑草稿后确认。切到 B 查看同一条记录及版号。小游戏从「功能 → 互动游戏」进入，先在共同回忆保存包含具体细节的素材。

运行测试可用 `python -m unittest discover -s services/couple/tests -t .`、`python -m unittest discover -s tests`。在 `apps/android` 执行 `flutter analyze --no-pub` 及 `flutter test --no-pub --dart-define=COUPLE_FIXTURE_URL=http://127.0.0.1:18793`；Flutter 联调测试应使用新启动的空白合成数据库。构建沿用根目录 `tools/build-test-apk.ps1`。

## 服务端版本

新 API 使用 SQLite schema 2。原分支的 schema 1 后端尚无模块续聊、意愿、委托、反馈和小游戏接口。隔离部署须使用本分支服务代码和独立数据卷；已有生产数据的备份、迁移和恢复操作由运维在另行安排时执行。[服务与数据库说明](../deploy/couple/MUSE.md)
