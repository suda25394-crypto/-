# Android 0.4 模拟器验收截图

2026-11-18，北京时间。测试员在一台 Android 13 模拟器中创建了两个独立系统用户，各自登录一个合成产品账号。App 通过回环地址连接本轮产品服务；模型、账号上游和工具提供方使用合成服务。以下图片都是 Android App 实际运行截图。

最终测试包为 `0.4.0+4`。从两个系统用户各自解析出的已安装 APK 计算 SHA-256，均为 `6bfa98dd4b3d171428fe1d10137cbe792f2b8a6e469087ed3f76bc757eb9dcde`。下表明确标出了在首轮构建上完成的部分。

最终后端保留同一份测试数据，再用最终 APK 重跑。A 在私人对话输入「把海风散步的周末计划改为下午四点半」，核对并确认终稿「周末改为下午四点半一起去海边」。即使上次已保存了相同正文，本次确认仍将原计划结构化集合时间更正为 `16:30`。B 强停重开在今日卡看到 `16:30 · 东门游客中心`，点开伴侣的更新看到 `16:00 → 16:30`。服务端同一日程从第 6 版变为第 7 版。该版只有一条变更，由 Alice 发起。[A 确认草稿](d48-a-approve-new-time.png) · [B 的首页](d48-b-confirmed-clock.png) · [B 的更新记录](d48-b-clock-change.png)

B 还在最终 APK 的共同空间依次发送普通消息和 `@DP` 消息。普通消息之后没有模型回复，明确呼叫后只出现一条合成回复；A 在独立 Android 用户重开同一共同空间看到相同三条消息，两会话读回的消息标识一致。[B 发送](d48-b-shared-message.png) · [A 查看](d48-a-shared-message.png)

此处只记录在模拟器上操作的项目。真实上游推理质量、独立工具账单、公网移动网络、两部实体手机、麦克风音质和扬声器播放质量仍需在相应环境检验。
